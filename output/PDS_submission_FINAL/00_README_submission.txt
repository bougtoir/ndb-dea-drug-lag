Pharmacoepidemiology and Drug Safety - submission package (FINAL)
=======================================================================

PDS_COVER_LETTER_FINAL.docx     Cover letter (author details to be completed locally)
PDS_MAIN_MANUSCRIPT_FINAL.docx  Main manuscript: title page (article type, running
                                head, corresponding author, authors/affiliations/
                                ORCID), structured abstract (Purpose/Methods/Results/
                                Conclusions, <=250 words), <=7 keywords, 5 Key Points,
                                Plain Language Summary (<=200 words), IMRaD text with
                                figures and tables inline, Word-native equations,
                                ethics/COI/funding/reporting-guideline/transparency
                                statements, references (Vancouver, order of appearance)
PDS_MAIN_MANUSCRIPT_INLINE_REVIEW.docx  Same content with figures/tables inline
                                (for local review; PDS accepts either layout)
PDS_TABLES_FINAL.docx           Tables 1-3 as separate editable files
PDS_STROBE_FINAL.docx           Completed STROBE checklist (Supplementary Material)
PDS_FIGURES_SOURCE.pptx         Figures 1-3, one per slide, editable
figures/Figure1-3.png           Individual figure files for upload
PDS_REQUIREMENTS_AUDIT.md       Current Wiley/PDS instructions vs this package
PDS_CITATION_ECOLOGY_AUDIT.md   PDS bibliographic-neighborhood / journal-fit audit
PDS_HOSTILE_REVIEW.md           Pre-submission hostile-reviewer self-audit
FINAL_HANDOFF_PDS.md            Build/handoff notes and unresolved human items

Every number, figure, and table is regenerated from the public NDB Open Data by the
pipeline in https://github.com/bougtoir/ndb-dea-drug-lag (download_ndb.py ->
build_dataset.py -> analyze.py -> course_estimate.py -> its_analysis.py ->
make_figures.py -> make_manuscript.py -> make_submission_zip.py --journal pds).
